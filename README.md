## About

I'm **Osarii**, a Computer Engineering student in Costa Rica who has worked the whole path from a fiber splice to a deployed web app.

I've done field telecom installs, on-site IT support and freelance full-stack work. Today I build software with AI agents doing real work (planning, writing, testing and reviewing code) inside guardrails I design, and I stay accountable for what ships.

The role I'm growing into is **Forward Deployed Engineer**: close to the people with the problem, fast from idea to working software, and honest about what is verified and what is not.

## How I build with AI

<div align="center">

  <source media="(prefers-color-scheme: dark)" srcset="assets/pipeline-dark.svg">

- **Multi-agent development.** I split work between coding agents (Claude Code, Codex, Gemini) with explicit contracts: file ownership, interfaces, limits and budgets. Their branches merge without manual rewrites.
- **Verification over trust.** An agent saying "done" isn't evidence. I rely on tests, mutation checks, end-to-end runs (Playwright, Vitest, `node --test`) and a recorded trail of what actually ran.
- **Humans keep the decision.** In clinical and engineering prototypes, deterministic engines are the source of truth. AI explains, and every write needs explicit human confirmation.
- **Automation that touches the real process.** I build n8n workflows (webhooks, branching, responses) wired into React front ends for bookings, invoicing and inventory alerts.
